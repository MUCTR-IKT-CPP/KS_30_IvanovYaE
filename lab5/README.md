# Лабораторная работа № 5, вариант 5

[Задание](https://github.com/MUCTR-IKT-CPP/cpp_course/blob/master/Лабораторные/lab5.md): аптечная система учёта. Реализованы базовая часть и усложнение на 90 дней.

Сборка и запуск из корня репозитория (C++11 или новее):

```sh
mkdir -p build
clang++ -std=c++11 -Wall -Wextra -Wpedantic lab5/main.cpp -o build/lab5
./build/lab5
```

Пример воспроизводимой симуляции на 90 дней:

```sh
printf '335\n90\n42\n' | ./build/lab5 > build/lab5-report.txt
```

Программа запрашивает начальную дату, длительность и seed генератора. Даты остаются в диапазоне 1–1000; для полного периода в 90 дней начальная дата должна быть не больше 911. Seed 0 выбирает случайное начальное состояние. Положительный seed воспроизводит результат при использовании одной реализации стандартной библиотеки C++.

`MedicalDrug` хранит общие данные, партии, остатки и статистику. Наследники `Tablets`, `Syrup`, `Ointment` добавляют дозировку, объём, вес, методы применения и разные условия хранения. Данные закрыты; изменение остатков выполняется через проверяемые методы. `Pharmacy` владеет объектами в трёх `vector`, ведёт историю продаж и денежный баланс. Шаблонные методы обработки коллекций и демонстрации применения обеспечивают статический полиморфизм. Указатели при выборе товара временные и не владеют памятью; удаление через базовый класс не используется.

Допущения модели:

- Генерируются 15–30 наименований каждого типа, по 20–60 упаковок. Названия и параметры учебные. Срок годности — 30–365 дней, начальная дата производства — от 1 до текущей даты включительно.
- Начальные запасы уже принадлежат аптеке, денежный баланс составляет 50 000 руб. Закупочная цена равна 60% розничной; новые поставки оплачиваются из баланса. Денежные операции выполняются в копейках.
- В начале каждого дня просроченные партии полностью списываются. При возрасте, равном сроку годности, продажа уже запрещена. При продаже сначала расходуются старые годные партии.
- При остатке строго менее 10% начального запаса утром заказывается свежая партия до исходного количества. У неё своя дата производства. Если средств недостаточно, поставка откладывается до следующего утра.
- Ежедневно приходят 5–20 покупателей. Каждый запрашивает 1–3 разных наименования по 1–3 упаковки каждого. Запрос с недостаточным годным остатком отклоняется целиком.
- Год содержит 365 дней: день 1 соответствует 1 января; зимние дни — 1–59 и 335–365. Календарь повторяется. Зимой вес выбора каждого противопростудного наименования увеличивается втрое.
- С вероятностью 30% действует общая дневная акция со случайной скидкой 5–15%. Цена упаковки после скидки округляется до копейки.
- Прибыль по препарату = выручка − закупочная стоимость проданных и списанных упаковок. Рентабельность = прибыль / эти затраты × 100%. Непроданные годные запасы остаются активом и не включаются в расходы периода; при нулевых затратах рентабельность не определена. Аренда, налоги и зарплаты в задании не заданы и в модель не входят.

Ежедневный отчёт содержит продажи, списания, поставки, выручку, баланс и все остатки с датами партий. Итоговый отчёт показывает общую выручку, оплаченные поставки, баланс и рентабельность каждого наименования.
